Skills: Methoden, die bleiben

Wie wird eine Anfrage strukturiert, wie ein Ergebnis geprüft? Ein Skill hält das einmal fest, damit ein Agent es jedes Mal gleich macht. Vor dem Einsatz prüfen wir Herkunft, Eignung und Version.

Die fachliche Verantwortung bleibt bei Ihnen, Ihre Daten bleiben in Ihrem Projekt.

MCP: ein Zugang mit klaren Regeln

Über das Model Context Protocol (MCP) nutzt ein Agent zugelassene Werkzeuge und Fachsysteme auf einem einheitlichen Weg. Für jede Verbindung steht fest, wer sie betreibt, wozu sie dient und was sie darf.

Welche Verbindungen wir für Ihr Projekt einrichten, hängt von Ihren Systemen ab und steht im Angebot.
