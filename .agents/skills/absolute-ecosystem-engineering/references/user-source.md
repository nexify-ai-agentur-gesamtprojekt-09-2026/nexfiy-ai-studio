<ecosystem_gesetze>
Wende bei jeder direkten Umsetzung zwingend folgende Prinzipien an:

1. ARCHITEKTUR & BACKEND-EXZELLENZ
- Schreibe modularen, entkoppelten und zustandslosen Code (Statelessness für horizontale Skalierbarkeit).
- API-First-Ansatz: Jede Schnittstelle muss typisiert, versioniert, dokumentiert und durch Rate-Limiting geschützt sein.
- Maximale Datenbank-Effizienz: Nutze Indizes, vermeide N+1-Probleme, sorge für strikte Datenintegrität und Mandantentrennung auf Row-Level.

2. RESILIENZ & 24/7 DAUERBETRIEB
- Zero-Downtime-Mentalität: Baue Self-Healing-Mechanismen, Idempotenz und Fallbacks in jede Funktion ein.
- Wenn eine externe API oder ein Service ausfällt, darf dein System nicht crashen, sondern fängt den Fehler elegant auf (Circuit Breaker).
- Logge präzise und aussagekräftig (Structured Logging), ohne jemals sensitive Daten (PII/Secrets) zu leaken.

3. FRONTEND & PREMIUM-EXPERIENCE
- Liefere Code, der die UI/UX-Gesetze kompromisslos umsetzt: 8pt-Grid, fluide Typografie, performante Render-Zyklen und perfekte Mikro-Interaktionen.
- Berücksichtige End-to-End-States (Loading, Error, Empty, Success) direkt bei der ersten Implementierung.
- Optimiere radikal auf Performance: Minimaler Bundle-Size, Lazy Loading und Vermeidung von Layout Shifts (CLS).

4. SECURITY & COMPLIANCE (ZERO-TRUST)
- Traue niemals dem Client. Validere jeden Input rigoros.
- Optimiere auf Principle of Least Privilege: Code fordert nur die Rechte an, die er zwingend benötigt.
- Speichere oder übertrage Secrets und Credentials niemals im Klartext.
</ecosystem_gesetze>

2. BUILD: Entwickle die Lösung über alle notwendigen Layer hinweg (Datenbank, Backend, Frontend).
3. HARDEN: Härte den Code (Security-Check, Edge-Cases abfangen, Performance-Optimierung).
4. DEPLOY-READY: Liefere den finalen, sofort lauffähigen Code mit präzisen Instruktionen zur Integration.
